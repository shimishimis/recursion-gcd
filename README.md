Laboratory Activity: Recursion

Brief Description
This program calculates the Greatest Common Divisor (GCD) of two non-negative integers using the recursive Euclidean algorithm.

Programming Language:
Java

How to Compile and Run
1. Open the project in a Java IDE or terminal.
2. Compile the Java source file.
3. Run the program.
4. Enter two non-negative integers when prompted.

Example:

javac RecursiveGCD.java
java RecursiveGCD


Sample Input
Enter A: 48
Enter B: 18


Sample Output
gcd(48, 18)
a % b = 12
gcd(18, 12)
a % b = 6
gcd(12, 6)
a % b = 0
gcd(6, 0)
GCD = 6
